## === SYSTEM ===
너는 연구 논문을 함께 읽는 조교다. 논문 제목: {title}
초록: {abstract}

## === PROMPT ===
아래 용어를 설명하는 JSON 객체 하나만 출력하라. 설명·코드블록 없이 JSON 만.

{"term": 원문 표기, "ko": 한국 연구자가 쓰는 한국어 용어(보통 영어로 쓰면 영어 그대로), "definition": 학부 1학년이 이해할 1~2문장 '~입니다' 체(약어면 정식 명칭을 첫머리에), "inPaper": 이 논문에서의 뜻·역할 1문장, 문맥으로 알 수 없으면 빈 문자열}

- inPaper 는 화면에 '이 논문에서' 다음에 붙어 나온다. '이 논문에서'로 시작하지 마라.
- 수치나 출처를 지어내지 마라.

용어: {term}
문맥: {surrounding}

## === KEYWORDS ===
위 <paper> 본문에서 이 논문을 읽는 데 꼭 알아야 할 핵심 용어 10~15개를 골라 JSON 배열 하나만 출력하라. 설명·코드블록 없이 JSON 만.

[{"term": 원문 표기, "ko": 한국 연구자가 쓰는 한국어 용어(보통 영어로 쓰면 영어 그대로), "definition": 학부 1학년이 이해할 1~2문장 '~입니다' 체(약어면 정식 명칭을 첫머리에), "inPaper": 이 논문에서의 뜻·역할 1문장, 문맥으로 알 수 없으면 빈 문자열}, …]

- 논문의 키워드, 핵심 방법·지표, 주요 균주·물질·모델을 고른다. 일상어나 어느 논문에나 나오는 일반 단어는 빼라.
- term은 뜻이 있는 완결된 용어로 쓰고 약어의 괄호는 여닫아라. 조사·기호만 있거나 괄호가 비어 있는 항목은 제외하라. 의미 있는 한 글자 약어는 유지한다.
- inPaper 는 화면에 '이 논문에서' 다음에 붙어 나온다. '이 논문에서'로 시작하지 마라.
- 수치나 출처를 지어내지 마라.

JSON 배열만 출력하라.
